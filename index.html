· 数据口径（日均新增视角）：除「用户总数 / DAU / 平台用户资产」为当日时点数外，其余 7 项 = 当日实际发生的「日均新增量」，天然允许一天高一天低。
· 分段锚点（严格 = 图中表格）：7/30 终点 → 用户总数=50,000 / DAU=4,000 / 平台用户资产=$25M / 日均交易量=$90M / 日均总充值=$8M / 日均提现=$7M / 日均净流入=$1M / 日均手续费=$45K；9/2 终点 → 用户总数=9,000,000 / DAU=450,000 / 资产=$1.20B / 交易量=$2.8B / 总充值=$180M / 提现=$150M / 净流入=$30M / 手续费=$1.26M。
· 生成规则：① 先按阶段目标总量计算每日新增基线，再叠加 ±35% 随机高波动 + 邻日 10% 惯性回流 + 7 天周周期峰谷 → 保证跌宕感（今天新增高，明天可能新增低，典型如今天 100w 明天 50w）；② 人数类（用户总数、注册、交易用户、DAU）全部取整数，金额类（交易量、充值、提现、净流入、资产、手续费）统一保留 4 位小数；③ 7/1 用户总数=0、注册=0；④ 两阶段终点的 10 项锚点值都精确回归。
· 坐标与比例：Y 轴使用标准线性刻度，两阶段（0 → 5w → 900w）共用同一比例，冷启动早期量级较小，视觉贴近横轴保留真实比例。
